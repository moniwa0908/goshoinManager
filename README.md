# 御翔印帳 Ver.1.1

iPhoneのホーム画面に追加して使える、御翔印収集管理用のPWAです。

## 主な機能
- 空港一覧
- 取得済み / 未取得管理
- 取得日
- メモ
- 御翔印写真
- 検索
- 絞り込み
- 並び替え
- 空港の追加・削除
- JSON完全バックアップ / 復元
- オフライン対応

## GitHub Pagesで公開する場合
1. このZIPを解凍
2. 中のファイルをGitHubリポジトリ直下へアップロード
3. Settings → Pages → Deploy from a branch
4. Branchを main / root にして保存
5. 発行されたURLをiPhoneのSafariで開く
6. 共有 → ホーム画面に追加
